## 驗收檢查

- CSV/XLSX raw parsers 略過開頭全空白列，並將第一個非空白列作為來源標題候選；不會越過 preamble 猜測後續標題。
- 任意、重複及空白標題依 zero-based source index 保留；CSV rows 超過 header 寬度時額外欄位也可見。
- 全空白資料列不回傳，但後續列保留原始 1-based row number。
- Empty/all-blank source returns `_header`; unreadable XLSX returns `_file`; missing sheet returns `_sheet`; all return `table: null`.
- Existing typed import and CSV/XLSX export round-trips remain covered and pass.
