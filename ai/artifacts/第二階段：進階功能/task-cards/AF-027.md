## Goal

Provide an accessible split mapping workspace that lets an admin connect uploaded source columns to the eight student profile targets and inspect a limited sample before requesting server validation.

## Context Pack

- Relevant files: `src/components/admin/AdminDictContext.tsx`, `src/components/admin/FileDropZone.tsx`, `src/components/admin/AdminDataTable.tsx`, `src/components/ui/select.tsx`, `src/components/ui/table.tsx`, three locale dictionaries, `ai/context/design-system.md`.
- Existing pattern: Admin components use `useAdminDict()` and shared shadcn-derived Table/Select/Button primitives. The wizard page currently owns upload/preview/result UI and is reserved to AF-021 integration.
- Assumptions: `sourceIndex` is the stable column identity; the component receives source columns, at most 3 sample rows, current mapping, and server/component errors through props.
- Unknowns: AF-028 owns the final request/response shape; the component API is finalized against the reviewed architecture contract before implementation.
- Allowed changes: New `src/components/admin/RegistrantColumnMapper.tsx`, focused component utility tests, the admin slices in `src/dictionaries/en.json`, `zh-hk.json`, `zh-cn.json`, `src/dictionaries/types.ts`, and `ai/context/design-system.md` inventory.
- Do not touch: Import wizard page/API routes, parser/business validation, database/schema, other admin pages, or unrelated dictionary text.

## Requirements

- Implement Variant C: target fields and mapping selectors on the left; a compact source sample table on the right.
- Render duplicate source labels with their column letter/index so they remain distinguishable.
- Expose controlled mapping changes using source indices; this component does not upload files or call APIs.
- Present required fields (`nameZh`, `nameEn`, `email`, `phone`, `idDocNumber`) separately from optional fields (`idDocType`, `iaLicense`, `organization`).
- Disable source options already assigned to another target; allow optional targets to remain unmapped and extra source columns to remain unused.
- Show no more than 3 sample rows. Before mapping, source values are visible only in the ADMIN flow; after mapping a source to `email`, `phone`, or `idDocNumber`, mask that column's displayed values.
- Show loading, empty, mapping-error, disabled, and read-only states through props; the page-level unauthorized/error boundary remains owned by AF-021.
- Use dictionary-driven text for en, zh-hk, and zh-cn; support keyboard selection, visible focus, and 44px touch targets.
- Register the new reusable component in `ai/context/design-system.md` after implementation.
