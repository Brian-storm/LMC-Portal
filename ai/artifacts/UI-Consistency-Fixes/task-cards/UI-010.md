## 目標

修復行動版裝置上 3 項重大與 2 項中度響應式問題，確保在所有中斷點（320px 以上）均有可用的版面與觸控體驗。

## 情境包（Context Pack）

- 相關檔案：
  - `src/app/layout.tsx` — 缺少 viewport export
  - `src/app/[locale]/admin/AdminLayoutClient.tsx` — sidebar 無行動版收合
  - `src/components/Navbar.tsx` — 無 resize 自動收合
  - `src/app/globals.css` — 缺少觸控/捲動最佳化
  - `src/components/courses/CourseCard.tsx` — flex-col 下 w-1/3 比例問題
- 既有模式：PortalLayoutClient 的 sidebar 使用 `fixed lg:sticky` + translate-x + backdrop 實作行動版抽屜
- 假設：Navbar 的行動選單在 window resize 到 md 以上應自動關閉
- 未知事項：AdminLayoutClient 是否應比照 PortalLayoutClient 的抽屜模式
- 允許變更的檔案：上述相關檔案
- 不得觸碰：無

## 需求

1. **Viewport meta tag**：在 `src/app/layout.tsx` 加入 `export const viewport = { width: "device-width", initialScale: 1 }`
2. **Admin 側邊欄收合**：在 AdminLayoutClient 加入類似 PortalLayoutClient 的 mobile hamburger + slide-in drawer + backdrop
3. **JS 中斷點偵測**：在 Navbar 與 Admin/Portal sidebar 加入 resize listener，當視窗寬度超過 md 時自動關閉行動選單
4. **觸控/捲動 CSS**：在 globals.css 加入 `-webkit-overflow-scrolling: touch`、`overscroll-behavior`、`touch-action` 最佳化
5. **CourseCard 比例修正**：在行動版 flex-col 佈局下讓圖片改用 `w-full` 而非 `w-1/3`
6. **Navbar clipPath 溢位**：檢查 logo 在多種手機寬度下是否造成 horizontal scroll，必要時加入 `overflow-x-hidden` 或調整 clipPath

## 驗收標準

- 手機瀏覽器（Chrome DevTools device emulation）在 320px-767px 所有寬度下無水平捲軸
- Admin 頁面在手機上 sidebar 收合為 hamburger 按鈕，點擊後 slide-in 覆蓋層
- Navbar 行動選單在縮放視窗超過 768px 時自動關閉
- 所有 overflow-x-auto 表格區塊在 iOS Safari 上有流暢的觸控滑動
- typecheck + lint 通過

## 實作備註

- PortalLayoutClient 的 sidebar 實作是現成可參考的模式（`fixed lg:sticky`、`translate-x-full`、`bg-slate-900/40` backdrop）
- 可能需引入 `useEffect` + `addEventListener("resize", ...)` 監聽中斷點
- 或使用第三方 hook 如 `@react-hook/media-query` 或 `use-media`（需確認是否已在專案中）
